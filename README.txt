NABELION AI TRADER — FREE ANDROID PWA
=====================================

WHAT THIS IS
A personal, installable web app for technical analysis. It is NOT an AI model,
broker, automatic trading bot, or guaranteed signal service. Its BUY WATCH /
SELL WATCH / WAIT decisions are generated by transparent indicator rules.

FILES
index.html       App screen
style.css        App design
app.js           Indicators, data request, risk calculator, TradingView chart
manifest.webmanifest  Android install metadata
sw.js            Offline app-shell cache
icon.svg         App icon

ANDROID SETUP (NO COMPUTER REQUIRED)
1. Download and extract nabelion_ai_trader.zip on your Android phone.
2. Install/open an Android code editor such as Acode (or use another editor).
3. Create a free GitHub account at https://github.com if you do not have one.
4. In GitHub, create a new PUBLIC repository named nabelion-ai-trader.
5. Upload all files from the extracted folder to the repository root. Do not
   upload only the ZIP file; upload index.html, app.js, style.css, etc.
6. In the repository open Settings -> Pages.
7. Under Build and deployment choose Deploy from a branch, select main and /root,
   then Save. Wait for GitHub Pages to publish the site.
8. Open the published HTTPS website in Chrome on Android.
9. Open Chrome menu (three dots) -> Install app or Add to Home screen.
10. Launch NABELION from your home screen.

CONNECT FREE MARKET DATA
1. Visit https://twelvedata.com/pricing and choose the $0 Basic plan.
2. Create an account and copy your API key from your dashboard.
3. Open NABELION -> Free data connection -> paste key -> Save on this phone.
4. Choose a symbol and timeframe -> Analyse market.

FREE PLAN LIMITATIONS
Twelve Data currently lists its Basic plan at 8 API credits/minute and 800/day.
Coverage and permissions vary by instrument and exchange. Its Basic plan lists
real-time forex, crypto and US equities/ETFs; commodities and some indices may
require a paid plan. Gold (XAU/USD) may therefore fail on the free tier.
TradingView's embedded chart is separate from the analysis data feed and may
show delayed or exchange-permission-limited prices.

SECURITY
This is a client-side personal prototype. Your Twelve Data key is saved in
browser localStorage and is visible to anyone who can inspect the app on your
phone or access its browser profile. Do not use this approach for a public
commercial app. A production app should use a secure backend and provider-
approved data licensing. Do not publish your API key in GitHub source code.

ANALYSIS RULES
EMA 9/21 trend, RSI(14), MACD direction, ATR(14), recent 20-candle support
and resistance. A directional WATCH requires 3 of 4 rule points. Stop/target
are illustrative ATR multiples, not personalized trade instructions.
Risk calculator shows account-risk cash amount only, not broker lot size.

TESTING
- Try EUR/USD, BTC/USD and AAPL first (subject to free-plan coverage).
- Compare the displayed latest candle/time and price with your broker.
- Try 1M, 5M, 15M, 1H and 4H.
- Confirm the app shows DATA ERROR when the provider rejects a symbol; never
  treat missing or stale data as a trade signal.
- Paper trade and backtest before considering live trading.
